# Supergoon Games Discord Bot

## A python app to handle webhooks and be a butler to sugergoon games

### Goals

- Something cool to keep me company in the server
- Keep myself and (maybe) others notified in the discord server when things change
- This was originally written in go by myself, and then converted to python by
    AI so that others can assist as it's easier for them to maintain.
- Deployed in the supergoon games k3s k8s cluster

### Description

- Makefile for local development testing.
- Http server that you can point webhooks to, and he can handle them accordingly
